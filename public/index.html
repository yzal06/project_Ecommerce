Đồng Bộ API Sàn Shopee & Lazada

Khi khách đặt hàng thành công trên website MintMart, hệ thống sẽ tự động gọi API của Shopee và Lazada để trừ kho tức thì, ngăn chặn tình trạng bán vượt số lượng tồn kho (over-selling).

Shopee Open Platform API

Endpoint: /api/v2/product/update_stock
Đang Kết Nối
Độ trễ: ~54ms

Lazada Open Platform API

Endpoint: /product/price_quantity/update
Tạm Ẩn API
API Lazada đang được tạm ẩn theo yêu cầu quản trị viên.
Đang tạm ngưng kết nối
